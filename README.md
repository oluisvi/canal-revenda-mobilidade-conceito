# Canal de revenda — mobilidade elétrica

Prévia estática de uma experiência comercial para lojistas: apresentação da linha, estados de disponibilidade, previsão informada pela equipe e consulta contextualizada por região.

## Limites do conceito

- Não representa uma empresa ou catálogo oficial.
- Produtos, disponibilidade, reposição e condições são demonstrativos e devem ser confirmados pela operação.
- A fotografia é uma referência real de scooter elétrica licenciada pela Unsplash; não identifica um produto específico nem confirma estoque.
- O formulário só simula uma consulta no navegador. Não envia dados e não está conectado a CRM, WhatsApp ou estoque.

## Fontes visuais
